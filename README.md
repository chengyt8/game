# 拼豆伙伴 · 乐园大冒险

一个**离线可玩**的 2D 平台跳跃小游戏。选择拼豆小牛或心形小狗，在乐园里跑、跳、冲刺，收集彩豆，冲进终点门、点亮整座乐园。

在线游玩：<https://chengyt8.github.io/game/>

## 🚀 怎么玩

- **方式一（推荐）**：本地服务器开着的话，直接打开 `http://127.0.0.1:4173/`
- **方式二（离线）**：双击 `index.html` 就能玩。不需要联网、不需要安装任何东西。

## 🎮 操作

| 动作 | 键盘 | 触屏 |
|---|---|---|
| 移动 | `←→` / `AD` | 左下虚拟方向键 |
| 跳跃 | `Space` / `↑` / `W`（按住跳更高） | 右下「跳」按钮 |
| 空中冲刺 | `J` / `Shift`（每次滞空一次） | 右下「冲刺」按钮 |
| 重开本关 | `R` | 暂停菜单里 |
| 暂停 | `P` / `Esc` | 暂停按钮 |
| 静音 | `M` | 右上角音符按钮 |

## 🗺 五关

1. **第 1 关 · 入口广场**（白天）：学移动和跳跃，收集彩豆，终点前拿到空中冲刺。
2. **第 2 关 · 云上步道**（多云）：用冲刺跨越长距离，弹簧弹上高架藏有秘密彩豆。
3. **第 3 关 · 摩天轮之夜**（夜晚）：移动平台 + 弹簧 + 一只可踩踏的巡逻敌人，终点点亮摩天轮。
4. **第 4 关 · 齿轮工坊**（黄昏）：尖刺走廊 + 移动平台躲开 6 格尖刺带，练精确跳跃。
5. **第 5 关 · 不夜城**（夜晚 · 终章）：两只巡逻敌人 + 移动平台 + 弹簧 + 尖刺，组合考验，点亮整座乐园。

## 无尽模式

通关第 1 关后解锁「无尽坠落」。小牛可以从持续上升的浮动楼梯起跳，向下转移以避免被顶出顶部；漏接平台掉到底部或踩到尖刺也会结束。部分楼梯会水平往返并携带小牛和彩球，同向移动更快、逆向移动更慢。

## ⭐ 计分

- 到达终点门即过关。
- 星级按彩豆收集率：过关 1 星、收集 ≥80% 2 星、**全收集且进入秘密区** 3 星。
- 秘密区没有可见边框，内部彩豆在发现前也不会显示；进入隐藏位置后才会显形。
- 每关有一个中段存档旗，死亡从最近存档点重生，已捡的彩豆会保留。

## 🔌 扩展入口

- **加新关**：复制一份 `js/content/levelN.js`，改平台/彩豆/敌人坐标，在 `js/content/manifest.js` 的 `levelOrder` 里登记即可——不用碰引擎代码。
- **换主角/加角色**：把拼豆图纸转成 `{ grid, palette }` 数据放进 `js/content/` 就行。
